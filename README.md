# Project Overview
GenAI Guide is a minimalist and professional static website designed to introduce users to Generative Artificial Intelligence (GenAI).

## This project provides:
- Clear explanations of GenAI
- Frequently asked questions
- Ethical guidelines for academic and real-world use
- A real-life analogy illustrating AI-assisted development

# How to Run the Project

## Open Directly (Fastest Method)
Download or clone the repository.
Open index.html in any modern web browser.

## Using VS Code Live Server
Open the project in Visual Studio Code.
Install the Live Server extension.
Right-click index.html → Open with Live Server.

## Frameworks / Technologies Used
